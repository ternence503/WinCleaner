【如何使用 / How to Use】

  最簡單方式（推薦）：
  Easiest method (Recommended):

  1. 雙擊「啟動清理工具.bat」
     Double-click "啟動清理工具.bat"

  2. 出現 UAC 視窗時選「是 / Yes」（需要管理員權限）
     Click "Yes" when UAC prompt appears (admin required)

  3. 選 [1] 一鍵全部清理，等待完成即可
     Choose [1] Full Clean and wait for completion

  備用方式 / Alternative:
  右鍵點擊「WinCleaner.ps1」→「以 PowerShell 執行」
  Right-click "WinCleaner.ps1" → "Run with PowerShell"


【清理項目說明 / What Gets Cleaned】

  1.  使用者暫存檔         - %TEMP% 資料夾內的暫存檔
  2.  系統暫存檔           - Windows\Temp 資料夾
  3.  Windows 更新快取     - 已下載的更新安裝包（可重新下載）
  4.  資源回收筒           - 清空所有磁碟的資源回收筒
  5.  瀏覽器快取           - Chrome / Edge / Firefox / IE / Brave
  6.  App 快取             - LINE / Discord / Teams / Slack / Zoom / Steam
  7.  Delivery Optimization - Windows P2P 更新快取
  8.  預先擷取檔案         - Windows\Prefetch（會自動重建）
  9.  縮圖快取             - 檔案總管縮圖（會自動重建）
  10. DNS 快取             - 網路 DNS 記錄（有助解決網路問題）
  11. 字型快取             - 字型資料庫（會自動重建）
  12. 錯誤報告             - Windows 錯誤記錄檔
  13. 舊版 Windows         - Windows.old 資料夾（需手動確認）
  14. 系統日誌             - 系統事件記錄檔
  15. 記憶體最佳化         - 釋放閒置的 RAM

【安全說明 / Safety Notes】

  ✓ 不會刪除您的個人檔案（文件、圖片、影片等）
  ✓ 不會刪除 LINE 對話紀錄、Discord 設定、瀏覽器書籤密碼
  ✓ 所有刪除操作都有錯誤處理，不會因為檔案被占用而崩潰
  ✓ Windows.old 刪除需要您手動確認
  ✓ 啟動項目停用可隨時從工作管理員還原
  ✓ 清理完成後建議重新啟動電腦

  It will NOT delete your personal files (documents, photos, videos)
  It will NOT delete LINE chats, Discord settings, or browser bookmarks
  All deletions handle errors gracefully
  Windows.old deletion requires your confirmation
  Restart recommended after cleaning


【常見問題 / FAQ】

  Q: 雙擊後出現藍色「Windows 已保護您的電腦」視窗
  A: 這是 Windows SmartScreen 對非知名發布者程式的正常警示，屬預期行為。
     點選視窗中的「其他資訊」，再點「仍要執行」即可繼續。

  Q: A blue "Windows protected your PC" screen appears after double-clicking
  A: This is normal SmartScreen behavior for tools without a paid code
     signing certificate. Click "More info", then "Run anyway" to continue.

  Q: 出現 UAC 視窗後我不小心點了「否」
  A: 沒關係，工具會顯示提示並安全結束，重新雙擊「啟動清理工具.bat」
     再點「是」即可，不會有任何檔案被誤刪。

  Q: I accidentally clicked "No" on the UAC prompt
  A: No problem — the tool shows a message and exits safely. Just double-click
     "啟動清理工具.bat" again and click "Yes" this time.

  Q: 執行後顯示「此系統上禁止執行腳本」
  A: 使用「啟動清理工具.bat」而非直接執行 .ps1

  Q: Script cannot be run on this system
  A: Use "啟動清理工具.bat" instead of running .ps1 directly

  Q: 清理後重開機桌面花一點時間載入？
  A: 正常！縮圖和圖示快取正在重建，只需一次。

  Q: Desktop takes longer to load after restart?
  A: Normal! Thumbnail and icon cache is rebuilding. One-time only.

  Q: 可以定期使用嗎？
  A: 可以！建議每 1~2 個月清理一次效果最好。

  Q: Can I use this regularly?
  A: Yes! Recommended once every 1-2 months for best results.


【版本更新 / Changelog】

  v3.8（2026-09-08，暫時診斷版）
  - v3.7 也沒解決中文亂碼（跟 v3.6 完全一樣），代表問題不在 chcp/編碼設定
    這一層，先加一段暫時的純 ASCII 診斷輸出，印出主控台實際的 codepage
    跟編碼狀態，用來找出真正原因。確認後這段診斷會移除

  v3.7（2026-09-08，放棄 Win7 強制 UTF-8）
  - 修正：v3.6 把 chcp 跟 Console.OutputEncoding 都設成 UTF-8 後，中文還是
    亂碼。查證後確認這是 Windows 7 舊版主控台（點陣字型）對 codepage 65001
    支援不完整的已知限制，不是設定沒對齊的問題。改為只在 PowerShell 3+／
    Windows 8 以後才切換 UTF-8；PS2／原生 Win7 維持系統原生 codepage
    （例如繁體中文的 950）完全不去動，本來就能正確顯示中文

  v3.6（2026-09-08，中文亂碼修正）
  - 修正：v3.5 解決了當機問題後，實測發現中文全部顯示亂碼。原因是只設定了
    .NET 的 Console.OutputEncoding=UTF8，主控台本身實際使用的 codepage 沒
    有跟著切換，兩邊對不上造成誤解讀。加上 chcp 65001 讓兩邊一致

  v3.5（2026-09-08，第三次實機測試後修正）
  - 修正：v3.4 只處理了「套色失敗」，但實測發現部分遠端桌面環境連無色的
    Write-Host 都會失敗；改為徹底繞過 Write-Host，失敗時改用 .NET Console
    類別直接寫入輸出資料流
  - 修正：全檔案 12 處空白行輸出（原本裸的 Write-Host ""）沒有套用保護，
    一併納入相同的容錯機制

  v3.4（2026-09-08，實機測試後再修正）
  - 修正：透過遠端桌面工具（AnyDesk 等）或部分虛擬機主控台執行時，彩色文字
    會讀取主控台緩衝區失敗，跳出大量「device...not functioning」錯誤並洗版；
    改為讀取失敗時自動退回無色輸出，畫面仍可正常顯示

  v3.3（2026-09-08，實機 Windows 7 測試後修正）
  - 修正：主選單用了 `-in` 運算子（PowerShell 3.0 才有），導致原生 Win7
    的 PowerShell 2.0 連整支腳本都無法解析，一啟動就報錯閃退
  - 修正：啟動項目管理用 [PSCustomObject] 轉換 hashtable（PS3+ 語意），
    在 PowerShell 2.0 上不會產生正確的具名屬性，改用相容寫法

  v3.2（2026-09-04）
  - 修正：原生 Windows 7（PowerShell 2.0）讀不到系統資訊、記憶體最佳化完全失效

  - 修正：點選 UAC 視窗「否」會顯示一堆看不懂的錯誤訊息後閃退，改為清楚的
    中英文提示並可安全重試
  - 修正：啟動器 .bat 內誤用 Mac/Linux 語法（/dev/null），Windows 上無效
  - 新增：SmartScreen 藍色警示視窗、UAC 誤按「否」的 FAQ 說明

  v3.1（2026-03-20）

  - 修正：PS1 加入 UTF-8 BOM，解決中文系統語法錯誤
  - 修正：中文介面文字重疊顯示問題
  - 修正：Delivery Optimization 清理指令名稱錯誤

  v3.0
